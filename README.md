# 📸 Photography Portfolio Website

A modern, fully-featured **photography portfolio website** built with cutting-edge web technologies. This platform showcases professional photography work while enabling seamless client bookings and inquiries.

## ✨ Features

### Gallery Experience
- Browse stunning photo collections with smooth, interactive galleries
- Dynamic image sliders for immersive visual storytelling
- Video showcase section for motion content and reels

### 👤 Professional Showcase
- Dedicated photographer bio and credentials
- Model collaboration section
- Team photo gallery display

### 💰 Transparent Pricing & Booking
- Clear pricing packages for different services
- Direct booking form for client inquiries
- Email notifications via integrated contact system

### 🎨 Enhanced User Experience
- Dark/Light theme toggle for comfort
- Smooth scroll animations and transitions
- Fully responsive design (mobile, tablet, desktop)
- Lightning-fast performance with Next.js

## 🛠️ Tech Stack

| Technology | Purpose |
|-----------|---------|
| **Next.js 16** (Turbopack) | Modern React framework with optimized performance |
| **React 19** | Component-based UI architecture |
| **Tailwind CSS 4** | Utility-first styling & responsive design |
| **Framer Motion** | Smooth animations & interactive elements |
| **Locomotive Scroll** | Premium smooth scrolling effects |
| **Next Themes** | Dark mode support |
| **Lucide React & React Icons** | Beautiful icon library |
| **Resend** | Email delivery for bookings & inquiries |

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed

### Installation

```bash
# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build & Deploy

```bash
# Build for production
npm run build

# Start production server
npm start
```
